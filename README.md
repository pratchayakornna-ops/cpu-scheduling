# เว็บการจัดตารางงานส่วนบุคคล ด้วย CPU Scheduling
## มินิโปรเจ็ควิชาระบบปฏิบัติการ (Operating Systems)

เว็บแอปพลิเคชันจำลองและเปรียบเทียบการจัดตารางเวลา CPU (CPU Scheduling) สำหรับการบริหารจัดการงานของนักศึกษา ออกแบบตรงตามข้อกำหนดในเอกสารใบงาน 10 หน้า ครบถ้วน 100%

---

### 🌟 ฟีเจอร์เด่นของระบบ

1. **3 อัลกอริทึมมาตรฐานตามโจทย์**:
   - **FCFS (First-Come, First-Served)**: ทำงานที่มาถึงก่อน เรียงตาม Arrival Time (AT) และ Process ID (P1 < P2 < ...)
   - **SJF (Shortest Job First - Non-preemptive)**: เลือกงานที่สั้นที่สุด (Burst Time ต่ำสุด) จากคิวที่พร้อมแล้ว (AT ≤ เวลาปัจจุบัน)
   - **Round Robin (RR)**: จัดสรรงานตาม Time Quantum $q$ ($1 \le q \le 4$) พร้อมกติกาพิเศษ: **งานใหม่ที่มาถึงตรงขอบเวลา $q$ จะเข้าคิวก่อนงานเดิมที่ยังไม่เสร็จ**

2. **ระบบสุ่มโจทย์และ Seed (Deterministic PRNG)**:
   - สุ่มงาน 4–6 วิชา พร้อมรหัส P1 ถึง Pn
   - AT สุ่ม 0–10 (รับประกันมี AT = 0 อย่างน้อย 1 งาน), BT สุ่ม 1–8
   - บันทึก Seed และชุดพารามิเตอร์ เพื่อเรียกโจทย์เดิมกลับมาได้ทุกครั้ง

3. **Gantt Chart & การแสดงผลเปรียบเทียบ**:
   - แสดง Gantt Chart ละเอียด มีสีสันแยกตาม Process และแถบแสดงช่วงเวลา CPU ว่าง (Idle)
   - กราฟเปรียบเทียบเวลารอเฉลี่ย (Average Waiting Time) และ Turnaround Time (TAT)
   - ตารางแจกแจงรอบของ Round Robin (ช่วงเวลา, งาน, เวลางานที่เหลือเมื่อจบรอบ) ตรงตามหน้า 5

4. **เครื่องมือจำลองการทำงานทีละก้าว (Step-by-Step Simulator)**:
   - ควบคุมการเล่น: เริ่มต้นใหม่, ถอยหลัง, เล่นต่อเนื่อง, ถัดไป
   - แสดงสถานะ CPU Core, นาฬิกาจำลอง $t$, และ Ready Queue แบบไดนามิก

5. **โหมดฝึกคำนวณด้วยมือ & ตรวจคำตอบ (Worksheet Practice)**:
   - รองรับการกรอกสมมติฐานก่อนคำนวณ (หน้า 6)
   - กรอกค่า CT, TAT, WT ที่คำนวณด้วยมือลงในตาราง (หน้า 7–9)
   - กดปุ่ม **"ตรวจเทียบกับโปรแกรม"** เพื่อตรวจความถูกต้องและไฮไลต์จุดที่แตกต่างทันที

6. **แล็บกรณีทดสอบพิเศษ (Edge Cases - หน้า 10)**:
   - ปุ่มโหลดเคสทดสอบ: งานมาพร้อมกัน & BT เท่ากัน, มีช่วง Idle, งานเข้าตรงขอบเวลา $q$, และตรวจสอบค่าผิดพลาด (BT=0, q=0)
   - การทดลองปรับเปลี่ยนค่า $q$ (q=1, 2, 3, 4) วิเคราะห์ผลกระทบต่อเวลารอและการสลับงาน

7. **พิมพ์ใบงานส่งอาจารย์ (1-Click Print / PDF Export)**:
   - จัดรูปแบบหน้ากระดาษ `@media print` ตรงตามแบบฟอร์มเอกสารใบงานมหาวิทยาลัย พร้อมข้อมูลผู้จัดทำและช่องลงชื่อ
